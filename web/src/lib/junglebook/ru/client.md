## Настройки клиента Hiddify

В панели Hiddify Manager порты для клиентов настраиваются автоматически при включении нужных протоколов. В самом приложении Hiddify App (HF-клиент) эти порты нужно связать с локальной работой через настройки входящих подключений (Inbounds), чтобы локальный прокси на вашем устройстве правильно перенаправлял трафик внутрь Hiddify.

## Резюме

- на андроид и iOS выбирайте TUN (vpn). Все просто работает.

- на десктопе Линукс TUN обычно не выбирайте: он требует повышенных прав  и перехватывает трафик на уровне ядра ОС, то есть создаёт виртуальный сетевой интерфейс в вашей ОС. Включайте TUN, только если понимаете его принцип работы — неумелое использование может нарушить сетевые настройки системы. Инструкция ниже.

- В большинстве случаев выбирайте System Proxy и оставляйте настройки приложений (Telegram/браузеры/расширения) по умолчанию, если они корректно используют системные настройки.

- Выбирайте Proxy (Inbounds/локальные порты), когда нужно вручную/точечно настроить приложения через разные порты и протоколы, либо если System Proxy по какой-то причине не применяется нужным приложением.

## Настройка портов в Hiddify App (клиент)

Порт прокси в HF-клиенте — это локальный порт на вашем устройстве (ПК или телефон). Он нужен для того, чтобы другие программы перенаправляли свой трафик в Hiddify. На этот порт программа‑клиент принимает соединения от других приложений.

- 1) Откройте приложение Hiddify.
- 2) Перейдите в Настройки (Settings) (иконка шестерёнки).
- 3) Откройте раздел Параметры ядра / Прокси (Core Settings / Inbounds).

Далее вы увидите основной локальный порт:

- Mixed Port (или HTTP/Socks Port) — локальный порт для работы с веб/смешанными подключениями. Часто по умолчанию стоит 2334 или 10808.

Mixed Port принимает оба типа подключений, и HTTP и SOCKS5, потому и Mixed. Но может быть указан отдельно Socks Port — локальный порт только для Socks5-трафика.

Если вы настраиваете стороннее приложение вручную (или расширение), то в нем укажите:
- Хост: 127.0.0.1
- Порт: номер из нужного пункта (например, из Mixed Port — 2334)

**В примерах Mixed Port равен 2334; у вас значение может быть другим — смотрите в настройках Inbounds**

В режиме Proxy (когда TUN выключен) порты: transparent proxy port, redirect port, direct port - не задействованы. Их можно игнорировать, они никак не влияют на работу локального прокси.

### Чем отличается HTTP и SOCKS5 (и что выбирать)

**HTTP-прокси**:
- подходит под веб-трафик HTTP/HTTPS
- обычно работает по TCP
- чаще всего используется для браузеров и веб-сценариев

**SOCKS5-прокси**:
- универсален: пересылает данные на более низком уровне и поддерживает любой трафик
- поддерживает TCP и UDP
- обычно лучше для мессенджеров, звонков, игр, торрентов

Что выбирать в контексте Hiddify:
- Если вы настраиваете сторонние приложения вручную через локальные порты HF-клиента,
  отдавайте приоритет SOCKS5 (особенно для Telegram).


### Настройка прокси в Telegram и браузере

При ручной настройке сторонних программ уточните фактический номер порта в разделе Inbounds — он мог быть изменён. Он универсален: один порт может работать и как HTTP, и как SOCKS5.

1) Настройка в Telegram (рекомендуется SOCKS5)

Для Telegram лучше использовать SOCKS5.

Откройте Telegram -> Настройки -> Продвинутые настройки -> Тип подключения
(в некоторых версиях: Данные и память -> Использование прокси).

Нажмите Добавить прокси и выберите тип SOCKS5.

Введите параметры:
- Хост (Хост/IP): 127.0.0.1
- Порт: 2334
- Пользователь и Пароль: оставьте пустыми

Сохраните и включите прокси.

2) Настройка в браузере

Современные браузеры используют системные настройки прокси Windows/macOS.

- Если в Hiddify включен System Proxy (Системный прокси), браузер уже автоматически работает через него, и настраивать ничего не нужно.
- Если System Proxy выключен, используйте расширение (например, FastProxy или Proxy SwitchyOmega):
  - установите расширение
  - создайте новый профиль
  - выберите протокол HTTP (или SOCKS5, если расширение поддерживает)
  - сервер: 127.0.0.1
  - порт: 2334


### Имеют ли смысл эти настройки, когда выбран TUN?

Короткий ответ: Да, имеют, но их роль меняется.

Когда в Hiddify включен режим TUN (Туннелирование), приложение создает виртуальный сетевой интерфейс, и весь трафик системы принудительно захватывается и направляется в Hiddify на системном уровне.

Как работают порты при TUN:
- Mixed Port (2334) — полезен. Даже при включенном TUN этот порт продолжает принимать локальные подключения.
  Это нужно, если вы хотите направить трафик отдельного приложения (или виртуалки), которое не замечает TUN,
  жестко прописав ему прокси 127.0.0.1:2334.

- Transparency Proxy Port (2335) и Redirect Port (2336) — нужны самому ядру TUN.
  Эти порты используются внутренними механизмами Hiddify (ядром Sing-box/Xray) для перехвата прозрачного трафика
  (TPROXY/REDIRECT). Ручной настройкой со стороны пользователя обычно не занимаются.

- Direct Port (2337) — служебный порт для пуска трафика в обход прокси (для сайтов-исключений).
  Его тоже не нужно прописывать в сторонние приложения вручную.

Резюме по TUN:
- При включенном TUN обычно не нужно вручную настраивать прокси в Telegram или браузере — они пойдут через Hiddify автоматически.
- Не рекомендуется менять эти порты вручную без крайней необходимости — на них завязана внутренняя логика разделения трафика, и неверные значения приведут к неработоспособности туннеля


## режим TUN (vpn)

чтобы в ТГ или браузере вообще не указывать порт, нужно включить режим TUN.

В этом режиме Hiddify создает в операционной системе виртуальную сетевую карту. Весь интернет-трафик вашего устройства автоматически и принудительно направляется в VPN на системном уровне [ссылка].

### Пошаговая настройка для Windows, macOS и Linux

Сбросьте настройки в программах (если меняли ранее):

- В Telegram: Зайдите в Настройки -> Продвинутые настройки -> Тип подключения и верните значение «Использовать системные настройки» (или «По умолчанию»).

- В браузере: Убедитесь, что сторонние расширения для прокси (вроде SwitchyOmega) отключены или переведены в режим «Системный прокси».

Включите режим TUN в Hiddify:

- Откройте приложение Hiddify.

- Перейдите в Настройки (Settings) -> Параметры ядра (Core Settings / Inbounds).

- Найдите пункт Режим работы (Service Mode / VPN mode) и выберите TUN вместо System Proxy или None.

- Примечание для Windows/Linux: Приложению могут потребоваться права администратора для создания виртуального сетевого адаптера. Если появится запрос UAC, подтвердите его.

Запустите подключение:

- Вернитесь на главный экран Hiddify и нажмите большую круглую кнопку «Подключиться» (Connect).

### Важный нюанс: root

запускать весь графический интерфейс Hiddify через sudo крайне не рекомендуется и небезопасно для Linux-системы.


## Сравнение: TUN vs Proxy vs System Proxy

### **TUN**

- **Что делает:** перехватывает сетевой трафик на уровне ОС через виртуальный сетевой интерфейс/перехват, чтобы “весь” трафик шел через Hiddify.
- **Кому помогает:** когда нужно, чтобы проксирование работало для большинства приложений автоматически, без настройки каждого по отдельности.
- **Последствие:** это именно “системное захватывание” трафика, поэтому обычно требует повышенных прав.

### **Proxy** (Inbounds / локальные порты)

- **Что делает:** поднимает **локальный прокси** (Mixed/Socks) на вашем устройстве.
- **Как используется:** вы вручную задаете этот локальный прокси в приложениях (Telegram, браузер через расширение, отдельные клиенты и т.п.).
- **Кому помогает:** когда не хотите включать TUN (или он недоступен), либо нужно направить трафик конкретного приложения, а не всего подряд.

### **System Proxy** (Системный прокси)
- **Что делает:** включает системные настройки прокси в ОС (или эмуляцию), чтобы браузер/приложения, которые следуют системным настройкам прокси, работали через Hiddify.
- **Кому помогает:** когда приложения корректно используют системный прокси и не требуется “тотальный” захват трафика.
- **Ограничение:** приложения, которые **не** берут настройки из системы, могут идти мимо.


### **TUN на Android**:

TUN на Android работает через встроенный VPN-интерфейс системы и не требует root. При первом включении Hiddify запросит разрешение на создание VPN-подключения — подтвердите его. Если root всё же есть, Hiddify может использовать продвинутый прозрачный перехват, но для обычной работы TUN это не нужно.
