# Книга Джунглей (Jungle Book)

Технический путеводитель по выживанию и обходу блокировок в современных цифровых джунглях. Настоящая документация содержит архитектурный разбор ядра Hiddify-Manager, прокси-протоколов и векторов развития систем глубокого анализа пакетов (DPI).

## Законы цифровых джунглей

1. Любой метод обхода эффективен лишь до тех пор, пока он неотличим от легитимного поведения миллиардов обычных пользователей.
2. Локальный цензор видит ваши магистральные провода, но корпоративный шпион контролирует саму среду вашего обитания.

Для перехода к чтению технических спецификаций выберите интересующий раздел в левом боковом меню навигации.
