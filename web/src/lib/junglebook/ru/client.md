## Настройки клиента Hiddify

В Hiddify Manager порты для клиентов настраиваются автоматически при включении нужных протоколов. В клиенте (Hiddify App) эти порты нужно связать с локальной работой через настройки входящих подключений (Inbounds).

Коротко о портах: это локальные порты на вашем устройстве, через которые другие программы (Telegram, браузер) перенаправляют свой трафик в Hiddify.

---

### Основные режимы работы

У Hiddify-клиента три основных режима:

- **TUN (VPN)** — перехватывает весь трафик системы на уровне ОС через виртуальный сетевой интерфейс. Всё работает автоматически, ничего настраивать в приложениях не нужно. На Android/iOS — стандартный выбор.
- **System Proxy** — включает системные настройки прокси в ОС. Приложения, которые их поддерживают (браузеры, некоторые мессенджеры), идут через Hiddify автоматически. Те, кто игнорирует системные настройки, — нет.
- **Proxy (Inbounds)** — поднимает локальный прокси-сервер (HTTP/SOCKS5) на определенном порту. Вы вручную прописываете этот прокси в нужных приложениях.

**Что выбрать:**
- Android/iOS — **TUN**. Просто работает.
- Десктоп (Windows/macOS) — обычно **System Proxy**, если приложения корректно его используют.
- Linux — **System Proxy** или **Proxy**, но не TUN без необходимости.
- Если нужно точечно направить только Telegram или браузер, а остальное оставить как есть — **Proxy**.

---

### Настройка портов (Inbounds)

В настройках Hiddify (Settings → Core Settings / Inbounds) вы увидите:

- **Mixed Port** (обычно 2334 или 10808) — принимает и HTTP, и SOCKS5. Универсальный порт.
- **Socks Port** (может быть отдельно, если Mixed отключен) — только SOCKS5.

Для ручной настройки в приложениях используйте:
- Хост: `127.0.0.1`
- Порт: номер из Mixed Port (например, `2334`)

Остальные порты (Transparent Proxy, Redirect, Direct) — служебные, нужны для внутренней работы ядра. В режиме Proxy они не задействованы, их можно игнорировать.

> **Важно:** порт может быть изменен — всегда смотрите фактическое значение в разделе Inbounds.

---

### Чем отличается HTTP от SOCKS5

| | HTTP-прокси | SOCKS5 |
|---|---|---|
| Для чего | Веб-трафик (браузеры) | Универсальный — любой трафик |
| Протоколы | TCP | TCP + UDP |
| Когда использовать | Браузеры, расширения | Мессенджеры, звонки, игры, торренты |

В контексте Hiddify: если настраиваете вручную, для Telegram выбирайте SOCKS5. Для браузера через расширение — HTTP или SOCKS5 (если расширение поддерживает).

---

### Настройка в приложениях

#### Telegram (рекомендуется SOCKS5)

1. Откройте Telegram → Настройки → Продвинутые настройки → Тип подключения (в некоторых версиях: Данные и память → Использование прокси).
2. Нажмите **Добавить прокси** → выберите **SOCKS5**.
3. Введите:
   - Хост: `127.0.0.1`
   - Порт: `2334` (или ваш фактический)
   - Пользователь и Пароль: оставить пустыми
4. Сохраните и включите прокси.

#### Браузер

- Если включен **System Proxy** — браузер уже идет через Hiddify, ничего настраивать не нужно.
- Если System Proxy выключен — используйте расширение (Proxy SwitchyOmega, FastProxy):
  1. Установите расширение.
  2. Создайте новый профиль.
  3. Выберите протокол HTTP (или SOCKS5, если поддерживается).
  4. Сервер: `127.0.0.1`, порт: `2334`.

---

### TUN-режим (VPN)

В этом режиме Hiddify создает виртуальную сетевую карту в ОС. Весь интернет-трафик автоматически направляется в VPN на системном уровне.

**Как включить:**

1. Сбросьте ручные настройки в приложениях:
   - Telegram: верните «Использовать системные настройки» (или «По умолчанию»).
   - Браузер: отключите расширения для прокси или переведите их в режим «Системный прокси».
2. В Hiddify: Настройки → Core Settings → Режим работы → выберите **TUN**.
3. Нажмите **Подключиться**.

**Важные нюансы:**

- На Windows/Linux могут потребоваться права администратора для создания адаптера.
- На Android/iOS TUN работает через встроенный VPN-интерфейс, root не нужен. При первом включении подтвердите разрешение.
- **Linux:** запускать графический интерфейс Hiddify через `sudo` крайне не рекомендуется — это небезопасно. TUN на Linux требует прав, но их можно дать отдельно, без запуска всего приложения от root.

**Как работают порты при TUN:**

- **Mixed Port** — продолжает работать. Можно использовать для ручного направления отдельных приложений, которые не замечают TUN.
- **Transparent Proxy / Redirect / Direct** — служебные, используются внутренними механизмами ядра. Вручную их не трогайте.

При включенном TUN обычно не нужно вручную настраивать прокси в Telegram или браузере — они пойдут через Hiddify автоматически.

---

### Сравнение режимов

| | TUN | System Proxy | Proxy (Inbounds) |
|---|---|---|---|
| Что делает | Перехватывает весь трафик на уровне ОС | Включает системный прокси | Поднимает локальный прокси-сервер |
| Для кого | Для всех приложений автоматически | Для приложений, которые берут системные настройки | Для ручной настройки конкретных приложений |
| Требует прав | Да (создание адаптера) | Нет | Нет |
| Когда использовать | Хотите, чтобы всё работало без настроек | Приложения нормально работают с системным прокси | Нужно точечное проксирование (только Telegram, только браузер) |
