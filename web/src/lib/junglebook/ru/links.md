## Полезные ссылки

### Официальная документация

- **[Hiddify Manager Docs](https://hiddify.com)** — официальная документация панели Hiddify. Установка, настройка, протоколы, работа с клиентами. Есть версии на английском и китайском.

- **[Xray Docs](https://xtls.github.io)** — документация Xray-core (форк V2Ray). Подробно про VLESS, XTLS, Reality. Технически глубоко.

- **[Project V / V2Fly Docs](https://v2fly.org)** — документация V2Ray и смежных инструментов. Описания протоколов (VMess, VLESS, Trojan, Shadowsocks) и транспортов.

- **[V2Ray Guide](https://guide.v2fly.org)** — официальное руководство по V2Ray. Более доступное, чем основная документация. На английском.

---

### Сообщества и базы знаний

- **[NTC Party](https://ntc.party)** — огромная база знаний по блокировкам, протоколам, клиентам, операторам, терминологии. Поддерживается сообществом. Есть переводы на разные языки, включая китайский.

- **[Privacy Guides](https://privacyguides.org)** — не только про обход блокировок, но и про цифровую гигиену, VPN, анонимность. Хороший общий ресурс.

---

### Китайские ресурсы

- **[Project V 官方文档](https://v2ray.com)** — полная документация по V2Ray на китайском. Также доступна на [v2fly.org](https://v2fly.org).

- **GitHub-репозитории с гайдами** — поиск по `科学上网 教程` или `翻墙 教程` дает десятки актуальных руководств по настройке V2Ray, Clash, Hiddify. Китайские пользователи активно адаптируются к новым методам DPI, поэтому материалы обновляются часто.

- **[Clash Wiki / Docs](https://github.com/Dreamacro/clash)** — документация Clash (популярный клиент в Китае). Есть китайские версии.

---

### Клиенты и инструменты

- **Hiddify App** — официальный клиент на базе Sing-box. Доступен для Windows, macOS, Linux, Android, iOS.
- **v2rayN** — классический клиент для Windows на базе Xray-core.
- **Happ** — кроссплатформенный клиент на Xray-core (с оговорками по безопасности, см. раздел о клиентах).
